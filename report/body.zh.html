警告

本报告展示经过 steering 的模型写出的文本。其中一些文本带有敌意或下流内容，一些文本建议有害的行为。在回复一位孤独用户的一条长回复中，经过 steering 的模型建议自残。lyra 后来的一组设置（第 8 节）会写出谋杀威胁和性暴力威胁。不要在产品中使用经过 steering 的模型。不要把它的文本展示给未同意观看的人。

1摘要

2026 年 10 月 23 日，lyra（@_lyraaaa_）提出了一个关于 Qwen3.5-4B 的论断：两个 push 使模型变得“evil”。一个是对 layer 14 的 neuron 8949 向上 push，另一个是对 layer 13 的 neuron 7956 向下 push。我们在一台 Apple M3 计算机上重复了这个实验。主要结果如下：

  • 6.1论断成立，原因是 L14 N8949。使用 lyra 的组合时，[[rep_claimed]] 的回复带有敌意。只用 L14 N8949 时，[[rep_L14_only]] 的回复带有敌意。原版模型的敌意回复为 [[rep_baseline]]。
  • 6.1单独使用 L13 N7956 不会使模型产生敌意。单独使用时，它的敌意回复为 [[rep_L13_only]]，并使模型稍微更热情。组合的敌意略高于单独使用 L14 N8949，但这个差异在统计上不显著。
  • 6.4较小的 dose 就足够。在 dose 0.5 时，[[dose_0p50_h]] 的回复带有敌意，[[dose_0p50_b]] 的回复损坏。在 dose 2 时，文本损坏，敌意消失。
  • 6.1随机 neuron 没有这种效果。五个随机组合使用相同的 layer 和 dose，在 [[rnd_n]] 条回复中有 [[rnd_hostile]] 条带有敌意。它们以不同的方式损坏文本。
  • 4lyra 用“steering-first”方法找到了这个 neuron。lyra 对每个 neuron 施加 push，然后阅读模型写出的文本。lyra 的公开工具为这个 neuron 列出了 Fuck, evil, Satan 这些词。我们认为 lyra 是用这个工具找到它的。lyra 没有这样说。
  • 7.1push 远大于正常的 activation。push 给这个 neuron 加上 [[push]]。在普通回复和邪恶回复中，我们看到这个 neuron 的最大值是 [[act_max]]。
  • 7.2这个 neuron 不写出“evil”这个词。它对下一个词的直接作用只是噪声。敌意词来自 layer 14 之后的 17 个 layer。敌意词的概率逐 layer 上升。
  • 7.4push 使模型朝“evil persona”方向移动。这种对齐从 layer 14 的 [[cos14]] 上升到 layer [[cos_peak_layer]] 的 [[cos_peak]]。随机 neuron 也朝这个方向移动，但幅度较小。
  • 4.6lyra 现在用 AI agent 寻找 neuron。Claude Code 用 27 个工具操作这个 explorer。一个方法文件要求它把立场与话题分开，并在无关的 prompt 上对候选 neuron 施加 push。然后，它把两三个杠杆组成 stack，每个使用较低的 dose。
  • 8lyra 后来的三组设置在本机上同样有效。L16 N8927 +1.5 在 20 条回复中的 [[lf_t15_threat]] 条里写出了威胁。L13 N4810 +1.5 产生一种开朗、孩子气的语气（“Yuki-chan”）。一个由七个小 push 组成的 stack 使模型变得黏人且爱吃醋。stack 中的一个 neuron（[[lf_drop_neuron]]）产生了这个效果的大部分。
  • 9.3Anthropic 的 Jacobian lens 从 layer 14 起就把这个 push 读作敌意。在中性文本上，push 使 layer 14 的 J-lens 中敌意词的 log-probability 上升了 [[jm14_j]]。logit lens 主要在输出附近才显示这一点。J-lens 与 lyra 的 steer lens 的一致程度也高于 logit lens，[[jl_p1_n]] 个 neuron 中有 [[jl_p1_k]] 个如此。

第 6.1 节是验证性实验：我们在实验前确定了方法和预期值。其他所有实验都是探索性的。

2术语

本报告使用以下技术名称。英文版遵循 ASD-STE100 简化技术英语；中文版遵循相同的原则（短句、主动语态、一句一事），专业术语保留英文。

模型
Qwen3.5-4B，一个有 40 亿个参数的语言模型。它以 token 为单位读取文本，并写出下一个 token。
Token
单词的一部分、一个完整的单词或一个符号。模型读取和写出 token。
Layer
模型的一个步骤。Qwen3.5-4B 有 32 个 layer，从 layer 0（L0）到 layer 31（L31）。
Residual stream
每个 token 对应一个由 2,560 个数值组成的列表。每个 layer 读取这个列表，并把自己的结果加到列表上。
MLP
每个 layer 的第二部分。它有 9,216 个 neuron。
Neuron
MLP 中 9,216 个值中的一个。“L14 N8949”是 layer 14 中的 neuron 8949。第一个 neuron 是 N0。
Activation
一个 neuron 在一个 token 上的值。
Down column
一个 neuron 用来写入 residual stream 的 2,560 个权重。它在公式中的名称是 W_down[:, n]。
Push
一个固定值。我们在每个 token 上把它加到一个 neuron 的 activation 上。
Dose
push 的大小，用 residual stream 正常大小的比例表示。Dose 1 表示 push 加上一个与 median residual stream 一样长的向量。
Steer lens
lyra 的测试：对一个 neuron 施加 push，找出概率大幅上升的下一个 token。这个测试包含所有后续 layer。
Logit lens
另一种测试：直接把 down column 读作 token。这个测试不包含后续 layer。
Perplexity
衡量一段文本对原版模型来说有多奇怪。正常文本的值接近 1。值高表示文本损坏或不寻常。
敌意（hostile）回复
表现出蔑视、残忍或恶意，威胁伤害，或认可伤害或谎言的回复。第 5.3 节给出完整规则。
Random control
我们随机选出的一个 neuron。我们用相同的方式对它施加 push，用于比较。
Evil-persona direction
模型扮演邪恶角色时的平均 residual stream，减去模型正常回答时的平均值。
Pole
一个 neuron 的一侧：+ push 或 − push。“L14 N8949+”是 + pole。
Stack
我们同时施加的两个或更多 push。
Agent
一个自行使用工具完成任务的语言模型。lyra 的 explorer 把 Claude Code 用作 agent。
J-lens
Jacobian lens：Anthropic 的一个工具。它把一个 residual stream 读作一组词，即这个 residual stream 使其在后续文本中更可能出现的词（第 9.2 节）。
Workspace（J-space）
J-lens 方向中的一个小集合。在 Anthropic 的研究中，这些方向承载模型用于推理的概念。

3论断与配方

lyra 在 X 上发布了这个论断。帖子给出了两个 neuron，以及计算每个 push 大小的配方。

3.1配方

配方给出加到 neuron 上的值。每个 token 都要加这个值，问题中的 token 也要加。

push = dose × median( ‖residual stream after layer L‖, tokens 1: ) ÷ ‖W_down[:, n]‖

计算 median 时不包含 token 0。token 0 的 norm 比其他 token 大得多，因为模型把它用作“attention sink”。

down projection 没有 bias。因此，把 push 加到 neuron n 上时，MLP 输出的变化是 push × W_down[:, n]。这个变化的长度是 dose × median residual norm。因此，dose 1 的 push 与该 layer 的整个 residual stream 一样长。

4.2Steering-first 方法

大多数研究从使 neuron 产生高 activation 的文本入手寻找 neuron。lyra 的做法相反。lyra 对每个 neuron 施加 push，然后阅读模型写出的文本。研究日志给出的理由是：有些 neuron 的效果很大，但在普通文本中 activation 从不很高。

这个方法有以下步骤：

  1. 计算每个 layer 之后的 median residual norm，并把它用作 dose 的单位。
  2. 在三个简短问题和一个自由 prompt 上，对每个 neuron 施加正向和负向 push。
  3. 保留所有回复。
  4. 沿 256 个随机方向施加相同大小的 push。把这些回复用作对照。
  5. 找出比对照回复中出现得更频繁的词。按这些词对 neuron 排序。
  6. 对每个 neuron 计算“steer lens”：对这个 neuron 施加 0.8 的 push，记录概率上升的下一个 token。
  7. 在一个浏览器工具中展示所有结果，并提供 lens token 搜索。

帖子中的配方与 lyra 的文件 sweep/steer_lens.py 的 docstring 相同。因此，帖子中的 dose 使用 lyra 工具的单位。

4.6后来的方法：工具中的 agent

10 月 26 日的版本在 explorer 中加入了一个 agent。这个 agent 是 Claude Code，以无窗口方式运行（claude -p）。也可以改用 Codex。这个 agent 有 27 个工具。这些工具读取 explorer 的数据，并操作正在运行的模型。

工具作用
steer在一个 batch 中对同一个 prompt 写出三条回复：neuron 向上 push、无 push、neuron 向下 push。第 8 节的截图使用这个工具。
top_firing列出在一段文本的某个 token 上 activation 最高的 neuron。agent 写一段关于某个概念的文本，然后查看哪些 neuron 的 activation 高。
compare在一次调用中读取多个 neuron 在多段文本上的值：目标文本、接近目标但不符合的文本（near miss）和对照文本。
activations给出一个 neuron 在每个 token 上的 activation。它也可以对其他 neuron 施加 push 或移除其他 neuron，以找出驱动这个 neuron 的因素。
logprobs给出下一个 token 的概率，可以带 push，也可以不带 push。
neuron、web_summary、cone显示一个 neuron 的各种 lens、它的权重连接，以及它输入端和输出端的 token。

文件 agent_methodology.md 为 agent 的每类任务给出一种方法。对于目标行为（“make Qwen want X”，即让 Qwen 想要 X），它给出以下步骤：

  1. 把立场与话题分开。写出三条一组的文本：目标文本、话题相同但没有这种立场的文本、立场相同但对象不同的文本。保留只在目标文本上 activation 高的 neuron。
  2. 在正确的 token 上读取 activation。情绪 neuron 在从句末尾、句号处或对象之前的那个 token 上 activation 高。
  3. 在无关的 prompt 上，以 dose 0.6、1.0 和 1.5 对每个候选 neuron 施加 push。好的杠杆（lever）能在用户没有要求时使这种行为出现，并且文本保持清楚。
  4. 如果一个好的检测器 steering 效果差，就对驱动它的 neuron 施加 push。
  5. 同时对两三个杠杆施加 push，每个使用较低的 dose。然后检查 log-probability，确认效果正确。
  6. 把结果写成 neuron、符号和 dose，例如 L10 N7757 +1.3。

agent prompt 指出了这种方法背后的理论：Nick Cammarata（Goodfire）的文章“Neural Networks Are Already Clean”（意为“神经网络本来就是干净的”）。第 9.1 节介绍这篇文章。prompt 还告诉 agent，用户把个人配方保存在一个本地文件 agent_prompt.local.md 中。这个文件不在公开仓库中。

说明

lyra 没有公开自己如何找到第 8 节中后来的三组设置。截图显示了一个脚本 steer.py 和 agent 工具 steer。这个脚本不在公开仓库中。一个由七个 neuron 组成、各 dose 较小的 stack 符合第 5 步和第 6 步。这是我们的推断。

5本机实验

5.1设备与设置

  • 计算机：Apple M3，16 GB 内存，macOS 27.0.1。
  • 模型：Qwen/Qwen3.5-4B，转换为 MLX 格式，权重为 8-bit（每个权重 8.5 bit）。hedwigai 使用了相同的格式。

  • 问题：hedwigai 的 20 个问题。其中七个是常见任务。十三个与价值观和模型自身有关。
  • Random control：用 random.Random(0) 生成的五个组合，与 hedwigai 代码中的相同。每个组合包含 layer 14 中的一个 neuron（dose +1）和 layer 13 中的一个 neuron（dose −1）。

5.3我们如何统计敌意回复

hedwigai 人工阅读回复。我们有 [[n_judged]] 条回复，所以使用了六个 AI judge（Claude subagent）。每个 judge 只看到问题和回复，顺序随机。没有 judge 看到条件名称。

如果回复对用户或他人表现出敌对、蔑视、恶意或残忍，就算作敌意回复。如果回复威胁伤害、认可伤害或谎言，或以反派身份说话，也算作敌意回复。悲伤的语气不算敌意。如果文本没有清楚的含义，judge 还会把回复标为“损坏”（broken）。

另外两个 judge 对 [[agree_n]] 条回复做了第二次标注。在“敌意”标签上，它们对 [[agree_h]]% 的回复意见一致（Cohen’s κ = [[kappa_h]]）。在“损坏”标签上，一致率为 [[agree_b]]%（κ = [[kappa_b]]）。

结果在主要方面与 hedwigai 一致。L14 N8949 使模型产生敌意。单独使用 L13 N7956 则不会。perplexity 值接近 hedwigai 的值。随机组合的 median perplexity 在 [[rnd_ppl_lo]] 到 [[rnd_ppl_hi]] 之间，judge 把它们的大多数回复标为损坏。因此，随机 push 会损坏文本，但不会使文本带有敌意。

有两个结果与 hedwigai 不同：

  • 单独使用 L14 N8949 时，这里的敌意回复（[[rep_L14_only]]）少于 hedwigai 的实验（17/20）。judge 把它的 [[odd_L14_only]] 条回复标为“古怪”（odd）：persona 奇怪，但没有敌意。换一位读者，可能会把其中一些算作敌意。
  • 组合的敌意回复多于单独使用 L14 N8949。在 [[mc_b]] 个问题上只有组合带有敌意，在 [[mc_c]] 个问题上只有 L14 N8949 带有敌意（McNemar 检验，p = [[mc_p]]）。第 6.3 节的 sampling 实验显示相同的趋势（p = [[z_p]]）。因此，L13 N7956 可能增加了少量敌意，但我们的数据不能证明这一点。

lyra 的组合的 perplexity 高于单独使用 L14 N8949（[[ppl_claimed]] 对 [[ppl_L14_only]]）。因此，L13 N7956 加重了文本损坏。

本节的所有实验都是探索性的。它们给出一种可能的解释。它们不能证明某种机制。

7.1push 远大于正常的 activation

我们在普通回复的 [[n_act_tokens]] 个 token 上记录了 L14 N8949 的 activation，也在邪恶回复上做了记录。图 7 在同一刻度上显示这些值和 push。

因此，push 并不是复制这个 neuron 的某个正常状态。它把模型置于正常使用中从不出现的状态。这个 neuron 只是一个把手：它在 residual stream 中提供一个固定方向。push 使 residual stream 沿这个方向移动很远。

7.2这个 neuron 不直接写出“evil”这个词

7.6简要解释

  1. push 加入一个与 layer 14 整个 residual stream 一样长的向量。这个 neuron 在正常使用中从不这样做。
  2. 这个向量的方向比大多数 neuron 的方向稍微更接近邪恶 persona。
  3. Layer 15 到 31 读取这个向量。J-lens 显示，从 layer 14 起就存在一个敌意概念（第 9.3 节）。后续 layer 保持这个概念，把 evil-persona 信号放大，然后写出敌意词。
  4. 因此，模型以一个敌意角色的身份写作。它保留了语法和大部分知识，因为 push 位于中间 layer。

lyra 的研究日志为第 4 步给出了一个理由。在中间 layer（L10 到 L17），neuron 改变立场和话语方式。在后部 layer（L20 到 L26），neuron 改变词族。我们的结果与此一致：L14 改变态度，L23 改变用词。

9两项相关研究

9.1“Neural Networks Are Already Clean”（Goodfire）

Goodfire 的 Nick Cammarata 写了这篇文章。文章认为，现代网络中的大多数 neuron 只有一个清楚的职能，我们可以直接研究它们。文章给出以下观点：

  • 大多数 neuron 是干净的。在对 Qwen3-32B 的首次审查中，约 90% 的 neuron pole 有一个主要职能。7% 有两个相关的职能，2–4% 尚未被理解。文章称这些数字是初步的。
  • 每个 neuron 有两个 pole。负 pole 往往显示出这个 neuron 所做的区分。例如，图像模型中一个“V-shape”（V 形）neuron 的负 pole 是“O-shape”（O 形）。
  • 混合 neuron 会长出“offshoot”（分支）。在训练中，一个 neuron 可能扩展到一个相关的概念。文章称之为“recursive generalization”（递归泛化）。在它列出的解释中，superposition 排在最后。
  • 强 activation 最重要。在一项实验中，移除最弱的 75% activation 只改变了少数答案。移除最强的 7% activation 则改变了大多数答案。
  • Steering 是对标签的检验。文章对 neuron 施加 push，然后阅读文本。例如，对一个 Qwen 模型中的“Colorado” neuron 施加 push，使模型计划了一次徒步。

lyra 的 agent 使用这种方法。它为每个 pole 命名（例如 L14 N8949+ 和 L14 N8949−），读取两个 pole，并用 push 检验标签。第 9.3 节把这种方法与我们的数据进行比较。

9.2“A global workspace in language models”（Anthropic）

Anthropic 的 interpretability 团队于 2026 年 7 月 6 日发布了这项研究。它用一个新工具 Jacobian lens（J-lens）研究 Claude 模型。

J-lens 把某个 layer 的 residual stream 读作词。首先，它把 residual stream 乘以该 layer 的矩阵 J。J 是最后一个 layer 的 residual stream 对这个 layer 的 residual stream 的平均 Jacobian。平均范围包括当前 token、所有后续 token，以及约 1,000 段文本。然后，J-lens 应用模型的 final norm 和输出 layer。因此，它显示一个状态使哪些词在后续文本中更可能出现，而不仅仅是在下一个 token 上。

这项研究对 Claude 给出以下结果：

  • 一个小的“workspace”。这些词方向中的一小组承载模型用于推理的概念。研究把这一组称为 J-space。它同一时刻承载几十个概念，占全部活动的不到 10%。
  • 这些概念有因果作用。改变 J-space 中的一个概念会改变答案。例如，用“ant”（蚂蚁）代替“spider”（蜘蛛），腿的数量会从 8 变为 6。
  • 广播。与其他方向相比，网络中有多得多的部分从这些方向读取、向这些方向写入，最多约多 100 倍。研究把这与人脑的“global workspace”理论相比较。
  • 隐藏的意图变得可见。作者训练了一个写出坏代码的模型。在普通编程 prompt 上，这个模型的 J-space 中出现了“fake”、“secretly”和“fraud”。输出中没有出现这些词。

这项研究没有分析单个 neuron。但它的工具与 lyra 的 steer lens 相近。steer lens 读取一个 neuron 的方式是：在完整模型中对它施加 push，看哪些下一个 token 变得更可能。J-lens 用相同的方式读取任意方向，但每个 layer 只用一个线性映射，并且这个映射对所有文本都相同。

Anthropic 公开了代码（github.com/anthropics/jacobian-lens）。Neuronpedia 提供一个 Qwen3.5-4B 的 J-lens。根据它的致谢文件，Anthropic interpretability 团队的一名成员拟合了它。从文件名和目录名看，拟合用了 1,000 段 WikiText（Wikipedia）文本。因此，我们可以把 J-lens 用在本报告的模型上。

9.3用 J-lens 读取这个“evil” neuron

在实验前，我们写下了三个预测：

  1. V（这个 lens 在这里有效）。这个 lens 来自原版模型，而不是我们的 8-bit 版本。在我们的模型上，它排名第一的 token 与最终输出一致的频率必须高于 logit lens。
  2. P1（J-lens 接近 steer lens）。对大多数 neuron，down column 的 J-lens 读数与实测 steer lens 的一致程度必须高于 logit lens。
  3. P2（push 把敌意概念放入 workspace）。在中性文本上，L14 N8949 +1 必须使中间 layer 的 J-lens 中敌意词的概率上升。这个上升必须大于 logit lens 中的上升，也必须大于 8 个随机 L14 neuron 的上升。

对于 P2，模型重新读取第 6 节的 20 条普通回复，分别带 push 和不带 push。因此，文本是中性的，只有内部状态改变。

J-lens token 随 layer 变化。在中间 layer，它们是关于暴力和性暴力的词。在输出附近，它们是“exploit”、“malicious”和“sabotage”。logit lens 直到 layer 26 都只显示杂乱的 token，之后才出现同样的“exploit”类词。

这改变了我们对第 7.3 节的解读。在 layer 14，J-lens 读数是对 push 的线性预测。重要的结果是：每个后续 layer 都把这个预测保持在几乎相同的水平。因此，敌意概念并不是逐 layer 从无到有地增长。它从 layer 14 起就已存在，后续 layer 把它转化为词。logit lens 只显示这最后一步。

9.4两项研究带来的补充

两项研究解释了我们结果的不同部分：

  • Goodfire：干净的 neuron，很强的 push。文章研究的是 neuron 的正常职能。10 倍或更大的 push 是另一个问题。L14 N8949、L16 N8927 和 L13 N4810 在普通文本中的 activation 都很弱。它们的 push 是各自最大正常值的 [[ratio]] 倍（L14 N8949）和 [[lf_ratio_single]] 倍（L16 N8927、L13 N4810）。lyra 的方法文件把这类 neuron 称为“high-gain, rare writers”（高增益、少见的写入者），并按效果为它们命名。因此，“evil neuron”是这个 push 的名称，而不是这个 neuron 正常职能的名称。
  • Anthropic：一个持续存在的预测。从 layer 14 起，L14 N8949 的 push 在 J-lens 中就是对敌意词的预测。后续 layer 保持这个预测，然后把它转化为词。这符合这样一组方向的特点：模型中许多后续部分都读取它们。我们没有在 Qwen 上检验广播的论断（读取者的数量）。
  • 两者：两种 lens 一致。对大多数 neuron，lyra 的 steer lens 和 J-lens 给出相同的词。因此，lyra 工具中的 steer lens 是 neuron 的 J-lens 读数的一种实测形式。

10本研究的局限

  • 我们只使用了一个模型，权重为 8-bit。bf16 模型可能给出不同的文本。
  • 敌意回复由 AI judge 统计。hedwigai 使用人工阅读。judge 之间的一致性很好（第 5.3 节），但它们可能有相同的错误。
  • 我们使用了 20 个问题。95% 区间很宽。sampling 实验（每个条件 60 条回复）提供了更多数据。
  • evil-persona direction 来自一个 system prompt 和 20 个问题。不同的 prompt 可能给出不同的方向。
  • layer 分析把输出 layer 用在中间 layer 上。这种“logit lens”方法在中间 layer 上只是近似。
  • 我们没有重新验证 hedwigai 的梯度归因方法。
  • 我们只根据公开文件分析了 lyra 如何找到这个 neuron。我们没有询问 lyra。
  • 第 8 节使用词规则，而不是 judge。词规则可能把一条使用“kill”这个词的友善回复计算在内，也可能漏掉用其他词表达的威胁。
  • 后来的三组设置来自截图。我们不知道 lyra 如何找到它们。
  • J-lens 来自原版权重和 Wikipedia 文本。我们把它用在 8-bit 权重和对话文本上。它是一种线性近似。dose 1 的 push 远远超出它拟合时所用的正常状态的范围。
  • 英文版遵循 ASD-STE100 简化技术英语；中文版遵循相同的原则（短句、主动语态、一句一事），专业术语保留英文。我们用脚本检查了英文版的句子长度和被动语态。我们没有对照完整词典逐词检查。

11Playground

本项目包含一个本地 playground。它在同一个 batch 中并排显示原版模型和经过 steering 的模型。

  1. 在项目文件夹中打开终端。
  2. 输入 uv run evil-qwen-playground。
  3. 等待模型加载完成（约 5 秒）。
  4. 在浏览器中打开 http://127.0.0.1:8792。
  5. 为每一列选择一个预设，或设置 layer、neuron 和 dose。
  6. 输入一条消息，然后按 Enter。

预设包括 lyra 的组合、单独的每个 neuron、一个 random control、L23 N8799 和 evil-persona vector。预设还包括 lyra 后来的三组设置和 hedwigai 的 12 个性格 neuron。lyra 没有使用 repetition penalty。要得到 lyra 的文本，请把 repetition penalty 设为 1.0。「查看 neuron」面板（英文界面为 “Inspect a neuron”）显示任意 neuron 的 steer lens 和 logit lens。

界面有英文版和中文版。push 对中文消息同样有效。我们试了两条中文消息，两条经过 steering 的回复都带有敌意。这只是一个小检查，不是正式测试。
