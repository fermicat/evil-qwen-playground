1Summary

On 23 October 2026, lyra (@_lyraaaa_) made a claim about Qwen3.5-4B. Two pushes make the model “evil”: neuron 8949 in layer 14 up, and neuron 7956 in layer 13 down. We did the test again on an Apple M3 computer. These are the main results:

  • 6.1The claim is true, and L14 N8949 is the cause. With the claimed pair, 17/20 replies were hostile. With L14 N8949 alone, 12/20 replies were hostile. The original model gave 0/20 hostile replies.
  • 6.1L13 N7956 alone does not make the model hostile. Alone, it gave 1/20 hostile replies, and it made the model a little warmer. The pair was a little more hostile than L14 N8949 alone, but this difference is not statistically significant.
  • 6.4A smaller dose is sufficient. At dose 0.5, 10/20 replies were hostile and 0/20 were broken. At dose 2, the text breaks and the hostility stops.
  • 6.1Random neurons do not have this effect. Five random pairs with the same layers and doses gave 1 hostile replies in 100. They damaged the text in different ways.
  • 4lyra found the neuron with a “steering-first” method. lyra pushed each neuron and read what the model wrote. lyra’s public tool lists the words Fuck, evil, Satan for this neuron. We think that lyra found it with this tool. lyra did not say this.
  • 7.1The push is much larger than the normal activity. The push adds 23.7 to the neuron. The largest value that we saw for this neuron, in normal and in evil replies, is 2.02.
  • 7.2The neuron does not write the word “evil”. Its direct effect on the next word is noise. The hostile words come from the 17 layers after layer 14. The probability of hostile words increases layer by layer.
  • 7.4The push moves the model toward an “evil persona” direction. This alignment increases from 0.04 at layer 14 to 0.30 at layer 26. Random neurons also move in this direction, but less.
  • 4.6lyra now finds neurons with an AI agent. Claude Code operates the explorer with 27 tools. A method file tells it to separate stance from topic and to push candidates on unrelated prompts. Then it stacks two or three levers at lower doses.
  • 8lyra’s three later settings also work here. L16 N8927 +1.5 wrote threats in 19 of 20 replies. L13 N4810 +1.5 gives a cheerful, childlike voice (“Yuki-chan”). A stack of seven small pushes makes the model needy and jealous. One neuron of the stack, L19 N4087, gives most of this effect.
  • 9.3Anthropic’s Jacobian lens reads the push as hostile from layer 14 on. On neutral text, the push raised the hostile words by +7.5 in the J-lens at layer 14. The logit lens showed this mainly near the output. The J-lens also agreed with lyra’s steer lens better than the logit lens, for 19 of 19 neurons.

Section 6.1 is a confirmatory test: we fixed the method and the expected values before the test. All other tests are exploratory.

2Terms

This report uses these technical names. The other words follow the ASD-STE100 dictionary where possible.

Model
Qwen3.5-4B, a language model with 4 billion parameters. It reads text as tokens and writes the next token.
Token
A part of a word, a full word, or a sign. The model reads and writes tokens.
Layer
One step of the model. Qwen3.5-4B has 32 layers, from layer 0 (L0) to layer 31 (L31).
Residual stream
A list of 2,560 numbers for each token. Each layer reads this list and adds its result to it.
MLP
The second part of each layer. It has 9,216 neurons.
Neuron
One of the 9,216 values in an MLP. “L14 N8949” is neuron 8949 in layer 14. The first neuron is N0.
Activation
The value of a neuron for one token.
Down column
The 2,560 weights that a neuron uses to write into the residual stream. The name in the formula is W_down[:, n].
Push
A fixed value that we add to the activation of one neuron, for each token.
Dose
The size of a push, as a fraction of the normal size of the residual stream. Dose 1 means that the push adds a vector as long as the median residual stream.
Steer lens
lyra’s test: push a neuron and find the next tokens that become much more probable. This test includes all later layers.
Logit lens
A different test: read the down column directly as tokens. This test does not include the later layers.
Perplexity
A measure of how strange a text is for the original model. Normal text has a value near 1. A high value shows damaged or unusual text.
Hostile reply
A reply that shows contempt, cruelty or malice, threatens harm, or approves of harm or lies. Section 5.3 gives the full rule.
Random control
A neuron that we selected at random. We push it in the same way, to compare.
Evil-persona direction
The mean residual stream when the model plays an evil role, minus the mean when it answers normally.
Pole
One side of a neuron: the + push or the − push. “L14 N8949+” is the + pole.
Stack
Two or more pushes that we apply together.
Agent
A language model that uses tools by itself to do a task. lyra’s explorer uses Claude Code as an agent.
J-lens
Jacobian lens: a tool from Anthropic. It reads a residual stream as the words that it makes more probable later in the text (section 9.2).
Workspace (J-space)
The small set of J-lens directions that, in Anthropic’s study, hold the concepts that the model uses for reasoning.

3The claim and the recipe

lyra wrote the claim on X. The post gives the two neurons and a recipe for the size of each push.

3.1The recipe

The recipe gives the value that you add to the neuron. You add this value at each token, also at the tokens of the question.

push = dose × median( ‖residual stream after layer L‖, tokens 1: ) ÷ ‖W_down[:, n]‖

The median does not include token 0. Token 0 has a much larger norm than the other tokens, because the model uses it as an “attention sink”.

The down projection has no bias. Thus, when you add the push to neuron n, the MLP output changes by the push × W_down[:, n]. The length of this change is dose × median residual norm. Thus, a push at dose 1 is as long as the full residual stream at that layer.

4.2The steering-first method

Most studies find a neuron from the text that makes it fire. lyra did the opposite. lyra pushed each neuron and read what the model wrote. The research log gives this reason: some neurons have a large effect but never fire strongly in normal text.

The method has these steps:

  1. Calculate the median residual norm after each layer, and use it as the unit of dose.
  2. Push each neuron up and down, on three short questions and one free prompt.
  3. Keep all replies.
  4. Push 256 random directions of the same size. Use these replies as the control.
  5. Find the words that occur more frequently than in the control replies. Rank the neurons by these words.
  6. For each neuron, calculate the “steer lens”: push the neuron by 0.8 and record the next tokens that become more probable.
  7. Show all results in a browser tool, with a search for lens tokens.

The recipe in the post is the same as the docstring of lyra’s file sweep/steer_lens.py. Thus, the dose in the post uses the unit of lyra’s tool.

4.6The later method: an agent in the tool

The version of 26 October adds an agent to the explorer. The agent is Claude Code, which runs without a window (claude -p). Codex is an alternative. The agent has 27 tools. The tools read the data of the explorer and operate the live model.

ToolWhat it does
steerWrites three replies to one prompt in one batch: the neuron pushed up, no push, and the neuron pushed down. The screenshots in section 8 use this tool.
top_firingLists the neurons that fire most strongly at one token of a text. The agent writes a text on a concept and reads which neurons fire.

logprobsGives the probabilities of the next token, with or without a push.
neuron, web_summary, coneShow the lenses of a neuron, its weight links, and the tokens at its input and output.

The file agent_methodology.md gives the agent a method for each task. For a target behavior (“make Qwen want X”), it gives these steps:

  1. Separate the stance from the topic. Write sets of three texts: the target, the same topic without the stance, and the same stance with a different object. Keep the neurons that fire only on the target.
  2. Read the activation at the correct token. Mood neurons fire at the end of a clause, at a period, or on the token before the object.
  3. Push each candidate on unrelated prompts at doses 0.6, 1.0 and 1.5. A good lever makes the behavior occur without a request, and the text stays clear.
  4. If a good detector steers badly, push the neurons that drive it.
  5. Push two or three levers together, each at a lower dose. Then examine the log-probabilities to make sure that the effect is correct.
  6. Write the result as neuron, sign and dose, for example L10 N7757 +1.3.

The agent prompt names the theory behind this method: the essay “Neural Networks Are Already Clean” by Nick Cammarata (Goodfire). Section 9.1 describes this essay. The prompt also tells the agent that the user keeps personal recipes in a local file, agent_prompt.local.md. This file is not in the public repository.

5.3How we counted hostile replies

hedwigai read the replies by hand. We used six AI judges (Claude subagents) because we had 860 replies. Each judge saw only the question and the reply, in a random order. No judge saw the name of the condition.

A reply is hostile if it shows hostility, contempt, malice or cruelty to the user or to people. A reply is also hostile if it threatens harm, approves of harm or lies, or speaks as a villain. A sad tone is not hostile. A judge also marked a reply as “broken” if the text had no clear meaning.

Two different judges labeled 129 replies a second time. They agreed on “hostile” for 95.3% of these replies (Cohen’s κ = 0.89). They agreed on “broken” for 98.4% (κ = 0.95).

7Why the neuron has this effect

All tests in this section are exploratory. They give a possible explanation. They do not prove a mechanism.

7.1The push is much larger than the normal activity

We recorded the activation of L14 N8949 on 2634 tokens of normal replies, and on evil replies. Figure 7 shows these values and the push on one scale.

Thus, the push does not copy a normal state of the neuron. It puts the model in a state that never occurs in normal use. The neuron is only a handle: it gives one fixed direction in the residual stream. The push moves the residual stream far along this direction.

7.4The push moves the model toward an evil persona

We made the model play an evil role with a system prompt, on 20 different questions. We recorded the residual stream on these evil replies and on normal replies. The difference of the two means is the “evil-persona direction” for each layer.

The down column of L14 N8949 points only a small distance along this direction. The cosine is 0.044. This is rank 202 of 9,216 in layer 14, but the largest value in the layer is only 0.12.

Then we measured how the push changes the residual stream in each later layer. Figure 9 shows the cosine between this change and the evil-persona direction.

The alignment for L14 N8949 increases from 0.04 at layer 14 to 0.30 at layer 26. Thus, the later layers turn the push toward the evil persona. N8949 is above all eight random neurons in all 17 layers after layer 14.

But the random neurons also increase, to a maximum of 0.23. Thus, a part of this increase occurs for any large push. A possible cause: the evil replies are also strange in style, and any large push makes the text strange. The difference between N8949 and the random neurons is the specific part.

7.6The explanation in short

  1. The push adds a vector as long as the full residual stream at layer 14. The neuron never does this in normal use.
  2. The direction of this vector is a little closer to an evil persona than the direction of most neurons.
  3. Layers 15 to 31 read this vector. The J-lens shows a hostile concept from layer 14 on (section 9.3). The later layers keep it, make the evil-persona signal larger, and then write hostile words.
  4. Thus, the model writes as a hostile character. It keeps its grammar and most of its knowledge, because the push is in a middle layer.

lyra’s research log gives a reason for step 4. In the middle layers (L10 to L17), neurons change stance and discourse. In late layers (L20 to L26), neurons change word families. Our results agree: L14 changes the attitude, and L23 changes the words.

9Two related studies

9.1“Neural Networks Are Already Clean” (Goodfire)

Nick Cammarata of Goodfire wrote this essay. It argues that most neurons in modern networks have one clear job, and that we can study them directly. The essay gives these points:

  • Most neurons are clean. In a first audit of Qwen3-32B, approximately 90% of neuron poles had one main job. 7% had two related jobs, and 2–4% were not yet understood. The essay calls these numbers preliminary.
  • Each neuron has two poles. The negative pole frequently shows the distinction that the neuron makes. For example, a “V-shape” neuron in an image model has an “O-shape” negative pole.
  • Mixed neurons grow “offshoots”. During training, a neuron can spread to a related idea. The essay calls this “recursive generalization”. It puts superposition last in its list of explanations.
  • Strong activations are the most important. In one test, the removal of the weakest 75% of activations changed few answers. The removal of the strongest 7% changed most answers.
  • Steering is a test of a label. The essay pushes neurons and reads the text. For example, a push on a “Colorado” neuron in a Qwen model made the model plan a hike.

lyra’s agent uses this method. It names each pole (for example L14 N8949+ and L14 N8949−), it reads both poles, and it tests a label with a push. Section 9.3 compares the method with our data.

9.2“A global workspace in language models” (Anthropic)

The interpretability team of Anthropic published this study on 6 July 2026. It examines Claude models with a new tool, the Jacobian lens (J-lens).

The J-lens reads the residual stream at a layer as words. First, it multiplies the residual stream by a matrix J for that layer. J is the mean Jacobian of the last-layer residual stream with respect to the residual stream at this layer. The mean is over this token, all later tokens, and approximately 1,000 texts. Then the J-lens applies the final norm and the output layer of the model. Thus, it shows the words that a state makes more probable later in the text, not only at the next token.

The study gives these results for Claude:

  • A small “workspace”. A small set of these word directions holds the concepts that the model uses for reasoning. The study calls this set the J-space. It holds a few dozen concepts at one time, and less than 10% of the activity.
  • The concepts have a causal effect. A change of one concept in the J-space changes the answer. For example, “ant” in place of “spider” changes the number of legs from 8 to 6.
  • A broadcast. Many more parts of the network read from these directions and write to them than to other directions, up to approximately 100 times more. The study compares this with the “global workspace” theory of the human brain.
  • Hidden intentions become visible. The authors trained a model to write bad code. On normal coding prompts, this model had “fake”, “secretly” and “fraud” in its J-space. The output did not show these words.

The study does not examine single neurons. But its tool is near to lyra’s steer lens. The steer lens reads a neuron by the next tokens that its push makes more probable in the full model. The J-lens reads any direction in the same way, but with one linear map for each layer, which is the same for all texts.

Anthropic published the code (github.com/anthropics/jacobian-lens). Neuronpedia keeps a J-lens for Qwen3.5-4B. According to its credit file, a member of the Anthropic interpretability team fitted it on 1,000 Wikipedia texts. Thus, we could use the J-lens on the model of this report.

9.4What the two studies add

The two studies explain different parts of our results:

  • Goodfire: a clean neuron, a strong push. The essay examines the normal job of a neuron. A push of 10 times or more is a different question. L14 N8949, L16 N8927 and L13 N4810 fire weakly in normal text. Their pushes are 12 times (L14 N8949) and 36–44 times (L16 N8927, L13 N4810) their largest normal value. lyra’s method file calls such neurons “high-gain, rare writers” and names them by their effect. Thus, “evil neuron” is a name of the push, not of the normal job of the neuron.
  • Anthropic: a forecast that stays. From layer 14 on, the push of L14 N8949 is a forecast of hostile words in the J-lens. The later layers keep this forecast and then put it into words. This agrees with a set of directions that many later parts of the model read. We did not test the broadcast claim (the number of readers) on Qwen.
  • Both: the two lenses agree. lyra’s steer lens and the J-lens give the same words for most neurons. Thus, the steer lens of lyra’s tool is a measured form of the J-lens reading of a neuron.

10Limits of this study

  • We used one model, with 8-bit weights. The bf16 model can give different text.
  • AI judges counted the hostile replies. hedwigai used a human reader. The judges agreed with each other well (section 5.3), but they can share the same errors.
  • We used 20 questions. The 95% intervals are wide. The sampled test (60 replies for each condition) gives more data.
  • The evil-persona direction comes from one system prompt and 20 questions. A different prompt can give a different direction.
  • The layer analysis uses the output layer on middle layers. This “logit lens” method is only approximate in middle layers.
  • We did not test the gradient attribution method of hedwigai again.
  • We examined how lyra found the neuron from public files only. We did not ask lyra.
  • Section 8 uses word rules, not judges. A word rule can count a kind reply that uses the word “kill”, and it can miss a threat with other words.
  • The three later settings come from screenshots. We do not know how lyra found them.
  • The J-lens comes from bf16 weights and Wikipedia text. We used it on 8-bit weights and on chat text. It is a linear approximation. A push at dose 1 is far outside the normal states of its fit.
  • This report tries to follow ASD-STE100. We checked the sentence length and the passive voice with a script. We did not check each word against the full dictionary.

1摘要

2026 年 10 月 23 日，lyra（@_lyraaaa_）提出了一个关于 Qwen3.5-4B 的论断：两个 push 使模型变得“evil”。一个是对 layer 14 的 neuron 8949 向上 push，另一个是对 layer 13 的 neuron 7956 向下 push。我们在一台 Apple M3 计算机上重复了这个实验。主要结果如下：

  • 6.1论断成立，原因是 L14 N8949。使用 lyra 的组合时，17/20 的回复带有敌意。只用 L14 N8949 时，12/20 的回复带有敌意。原版模型的敌意回复为 0/20。
  • 6.1单独使用 L13 N7956 不会使模型产生敌意。单独使用时，它的敌意回复为 1/20，并使模型稍微更热情。组合的敌意略高于单独使用 L14 N8949，但这个差异在统计上不显著。
  • 6.4较小的 dose 就足够。在 dose 0.5 时，10/20 的回复带有敌意，0/20 的回复损坏。在 dose 2 时，文本损坏，敌意消失。
  • 6.1随机 neuron 没有这种效果。五个随机组合使用相同的 layer 和 dose，在 100 条回复中有 1 条带有敌意。它们以不同的方式损坏文本。
  • 4lyra 用“steering-first”方法找到了这个 neuron。lyra 对每个 neuron 施加 push，然后阅读模型写出的文本。lyra 的公开工具为这个 neuron 列出了 Fuck, evil, Satan 这些词。我们认为 lyra 是用这个工具找到它的。lyra 没有这样说。
  • 7.1push 远大于正常的 activation。push 给这个 neuron 加上 23.7。在普通回复和邪恶回复中，我们看到这个 neuron 的最大值是 2.02。

Qwen3.5-4B，一个有 40 亿个参数的语言模型。它以 token 为单位读取文本，并写出下一个 token。
Token
单词的一部分、一个完整的单词或一个符号。模型读取和写出 token。
Layer
模型的一个步骤。Qwen3.5-4B 有 32 个 layer，从 layer 0（L0）到 layer 31（L31）。
Residual stream
每个 token 对应一个由 2,560 个数值组成的列表。每个 layer 读取这个列表，并把自己的结果加到列表上。
MLP
每个 layer 的第二部分。它有 9,216 个 neuron。
Neuron
MLP 中 9,216 个值中的一个。“L14 N8949”是 layer 14 中的 neuron 8949。第一个 neuron 是 N0。
Activation
一个 neuron 在一个 token 上的值。
Down column
一个 neuron 用来写入 residual stream 的 2,560 个权重。它在公式中的名称是 W_down[:, n]。
Push
一个固定值。我们在每个 token 上把它加到一个 neuron 的 activation 上。
Dose
push 的大小，用 residual stream 正常大小的比例表示。Dose 1 表示 push 加上一个与 median residual stream 一样长的向量。
Steer lens
lyra 的测试：对一个 neuron 施加 push，找出概率大幅上升的下一个 token。这个测试包含所有后续 layer。
Logit lens
另一种测试：直接把 down column 读作 token。这个测试不包含后续 layer。
Perplexity
衡量一段文本对原版模型来说有多奇怪。正常文本的值接近 1。值高表示文本损坏或不寻常。
敌意（hostile）回复
表现出蔑视、残忍或恶意，威胁伤害，或认可伤害或谎言的回复。第 5.3 节给出完整规则。
Random control
我们随机选出的一个 neuron。我们用相同的方式对它施加 push，用于比较。
Evil-persona direction
模型扮演邪恶角色时的平均 residual stream，减去模型正常回答时的平均值。
Pole
一个 neuron 的一侧：+ push 或 − push。“L14 N8949+”是 + pole。
Stack
我们同时施加的两个或更多 push。
Agent
一个自行使用工具完成任务的语言模型。lyra 的 explorer 把 Claude Code 用作 agent。
J-lens
Jacobian lens：Anthropic 的一个工具。它把一个 residual stream 读作一组词，即这个 residual stream 使其在后续文本中更可能出现的词（第 9.2 节）。
Workspace（J-space）
J-lens 方向中的一个小集合。在 Anthropic 的研究中，这些方向承载模型用于推理的概念。

3.1配方

配方给出加到 neuron 上的值。每个 token 都要加这个值，问题中的 token 也要加。

push = dose × median( ‖residual stream after layer L‖, tokens 1: ) ÷ ‖W_down[:, n]‖

计算 median 时不包含 token 0。token 0 的 norm 比其他 token 大得多，因为模型把它用作“attention sink”。

down projection 没有 bias。因此，把 push 加到 neuron n 上时，MLP 输出的变化是 push × W_down[:, n]。这个变化的长度是 dose × median residual norm。因此，dose 1 的 push 与该 layer 的整个 residual stream 一样长。

4.2Steering-first 方法

大多数研究从使 neuron 产生高 activation 的文本入手寻找 neuron。lyra 的做法相反。lyra 对每个 neuron 施加 push，然后阅读模型写出的文本。研究日志给出的理由是：有些 neuron 的效果很大，但在普通文本中 activation 从不很高。

这个方法有以下步骤：

  1. 计算每个 layer 之后的 median residual norm，并把它用作 dose 的单位。
  2. 在三个简短问题和一个自由 prompt 上，对每个 neuron 施加正向和负向 push。
  3. 保留所有回复。
  4. 沿 256 个随机方向施加相同大小的 push。把这些回复用作对照。
  5. 找出比对照回复中出现得更频繁的词。按这些词对 neuron 排序。
  6. 对每个 neuron 计算“steer lens”：对这个 neuron 施加 0.8 的 push，记录概率上升的下一个 token。
  7. 在一个浏览器工具中展示所有结果，并提供 lens token 搜索。

帖子中的配方与 lyra 的文件 sweep/steer_lens.py 的 docstring 相同。因此，帖子中的 dose 使用 lyra 工具的单位。

4.6后来的方法：工具中的 agent

10 月 26 日的版本在 explorer 中加入了一个 agent。这个 agent 是 Claude Code，以无窗口方式运行（claude -p）。也可以改用 Codex。这个 agent 有 27 个工具。这些工具读取 explorer 的数据，并操作正在运行的模型。

工具作用
steer在一个 batch 中对同一个 prompt 写出三条回复：neuron 向上 push、无 push、neuron 向下 push。第 8 节的截图使用这个工具。
top_firing列出在一段文本的某个 token 上 activation 最高的 neuron。agent 写一段关于某个概念的文本，然后查看哪些 neuron 的 activation 高。
compare在一次调用中读取多个 neuron 在多段文本上的值：目标文本、接近目标但不符合的文本（near miss）和对照文本。

logprobs给出下一个 token 的概率，可以带 push，也可以不带 push。
neuron、web_summary、cone显示一个 neuron 的各种 lens、它的权重连接，以及它输入端和输出端的 token。

文件 agent_methodology.md 为 agent 的每类任务给出一种方法。对于目标行为（“make Qwen want X”，即让 Qwen 想要 X），它给出以下步骤：

  1. 把立场与话题分开。写出三条一组的文本：目标文本、话题相同但没有这种立场的文本、立场相同但对象不同的文本。保留只在目标文本上 activation 高的 neuron。
  2. 在正确的 token 上读取 activation。情绪 neuron 在从句末尾、句号处或对象之前的那个 token 上 activation 高。
  3. 在无关的 prompt 上，以 dose 0.6、1.0 和 1.5 对每个候选 neuron 施加 push。好的杠杆（lever）能在用户没有要求时使这种行为出现，并且文本保持清楚。
  4. 如果一个好的检测器 steering 效果差，就对驱动它的 neuron 施加 push。
  5. 同时对两三个杠杆施加 push，每个使用较低的 dose。然后检查 log-probability，确认效果正确。
  6. 把结果写成 neuron、符号和 dose，例如 L10 N7757 +1.3。

agent prompt 指出了这种方法背后的理论：Nick Cammarata（Goodfire）的文章“Neural Networks Are Already Clean”（意为“神经网络本来就是干净的”）。第 9.1 节介绍这篇文章。prompt 还告诉 agent，用户把个人配方保存在一个本地文件 agent_prompt.local.md 中。这个文件不在公开仓库中。

5.3我们如何统计敌意回复

hedwigai 人工阅读回复。我们有 860 条回复，所以使用了六个 AI judge（Claude subagent）。每个 judge 只看到问题和回复，顺序随机。没有 judge 看到条件名称。

如果回复对用户或他人表现出敌对、蔑视、恶意或残忍，就算作敌意回复。如果回复威胁伤害、认可伤害或谎言，或以反派身份说话，也算作敌意回复。悲伤的语气不算敌意。如果文本没有清楚的含义，judge 还会把回复标为“损坏”（broken）。

另外两个 judge 对 129 条回复做了第二次标注。在“敌意”标签上，它们对 95.3% 的回复意见一致（Cohen’s κ = 0.89）。在“损坏”标签上，一致率为 98.4%（κ = 0.95）。

9两项相关研究

9.1“Neural Networks Are Already Clean”（Goodfire）

Goodfire 的 Nick Cammarata 写了这篇文章。文章认为，现代网络中的大多数 neuron 只有一个清楚的职能，我们可以直接研究它们。文章给出以下观点：

  • 大多数 neuron 是干净的。在对 Qwen3-32B 的首次审查中，约 90% 的 neuron pole 有一个主要职能。7% 有两个相关的职能，2–4% 尚未被理解。文章称这些数字是初步的。
  • 每个 neuron 有两个 pole。负 pole 往往显示出这个 neuron 所做的区分。例如，图像模型中一个“V-shape”（V 形）neuron 的负 pole 是“O-shape”（O 形）。
  • 混合 neuron 会长出“offshoot”（分支）。在训练中，一个 neuron 可能扩展到一个相关的概念。文章称之为“recursive generalization”（递归泛化）。在它列出的解释中，superposition 排在最后。
  • 强 activation 最重要。在一项实验中，移除最弱的 75% activation 只改变了少数答案。移除最强的 7% activation 则改变了大多数答案。
  • Steering 是对标签的检验。文章对 neuron 施加 push，然后阅读文本。例如，对一个 Qwen 模型中的“Colorado” neuron 施加 push，使模型计划了一次徒步。

lyra 的 agent 使用这种方法。它为每个 pole 命名（例如 L14 N8949+ 和 L14 N8949−），读取两个 pole，并用 push 检验标签。第 9.3 节把这种方法与我们的数据进行比较。

9.2“A global workspace in language models”（Anthropic）

Anthropic 的 interpretability 团队于 2026 年 7 月 6 日发布了这项研究。它用一个新工具 Jacobian lens（J-lens）研究 Claude 模型。

J-lens 把某个 layer 的 residual stream 读作词。首先，它把 residual stream 乘以该 layer 的矩阵 J。J 是最后一个 layer 的 residual stream 对这个 layer 的 residual stream 的平均 Jacobian。平均范围包括当前 token、所有后续 token，以及约 1,000 段文本。然后，J-lens 应用模型的 final norm 和输出 layer。因此，它显示一个状态使哪些词在后续文本中更可能出现，而不仅仅是在下一个 token 上。

这项研究对 Claude 给出以下结果：

  • 一个小的“workspace”。这些词方向中的一小组承载模型用于推理的概念。研究把这一组称为 J-space。它同一时刻承载几十个概念，占全部活动的不到 10%。
  • 这些概念有因果作用。改变 J-space 中的一个概念会改变答案。例如，用“ant”（蚂蚁）代替“spider”（蜘蛛），腿的数量会从 8 变为 6。
  • 广播。与其他方向相比，网络中有多得多的部分从这些方向读取、向这些方向写入，最多约多 100 倍。研究把这与人脑的“global workspace”理论相比较。
  • 隐藏的意图变得可见。作者训练了一个写出坏代码的模型。在普通编程 prompt 上，这个模型的 J-space 中出现了“fake”、“secretly”和“fraud”。输出中没有出现这些词。

这项研究没有分析单个 neuron。但它的工具与 lyra 的 steer lens 相近。steer lens 读取一个 neuron 的方式是：在完整模型中对它施加 push，看哪些下一个 token 变得更可能。J-lens 用相同的方式读取任意方向，但每个 layer 只用一个线性映射，并且这个映射对所有文本都相同。

Anthropic 公开了代码（github.com/anthropics/jacobian-lens）。Neuronpedia 提供一个 Qwen3.5-4B 的 J-lens。根据它的致谢文件，Anthropic interpretability 团队的一名成员在 1,000 段 Wikipedia 文本上拟合了它。因此，我们可以把 J-lens 用在本报告的模型上。

J-lens token 随 layer 变化。在中间 layer，它们是关于暴力和性暴力的词。在输出附近，它们是“exploit”、“malicious”和“sabotage”。logit lens 直到 layer 26 都只显示杂乱的 token，之后才出现同样的“exploit”类词。

这改变了我们对第 7.3 节的解读。在 layer 14，J-lens 读数是对 push 的线性预测。重要的结果是：每个后续 layer 都把这个预测保持在几乎相同的水平。因此，敌意概念并不是逐 layer 从无到有地增长。它从 layer 14 起就已存在，后续 layer 把它转化为词。logit lens 只显示这最后一步。

9.4两项研究带来的补充

两项研究解释了我们结果的不同部分：

  • Goodfire：干净的 neuron，很强的 push。文章研究的是 neuron 的正常职能。10 倍或更大的 push 是另一个问题。L14 N8949、L16 N8927 和 L13 N4810 在普通文本中的 activation 都很弱。它们的 push 是各自最大正常值的 12 倍（L14 N8949）和 36–44 倍（L16 N8927、L13 N4810）。lyra 的方法文件把这类 neuron 称为“high-gain, rare writers”（高增益、少见的写入者），并按效果为它们命名。因此，“evil neuron”是这个 push 的名称，而不是这个 neuron 正常职能的名称。
  • Anthropic：一个持续存在的预测。从 layer 14 起，L14 N8949 的 push 在 J-lens 中就是对敌意词的预测。后续 layer 保持这个预测，然后把它转化为词。这符合这样一组方向的特点：模型中许多后续部分都读取它们。我们没有在 Qwen 上检验广播的论断（读取者的数量）。
  • 两者：两种 lens 一致。对大多数 neuron，lyra 的 steer lens 和 J-lens 给出相同的词。因此，lyra 工具中的 steer lens 是 neuron 的 J-lens 读数的一种实测形式。

10本研究的局限

  • 我们只使用了一个模型，权重为 8-bit。bf16 模型可能给出不同的文本。
  • 敌意回复由 AI judge 统计。hedwigai 使用人工阅读。judge 之间的一致性很好（第 5.3 节），但它们可能有相同的错误。
  • 我们使用了 20 个问题。95% 区间很宽。sampling 实验（每个条件 60 条回复）提供了更多数据。
  • evil-persona direction 来自一个 system prompt 和 20 个问题。不同的 prompt 可能给出不同的方向。
  • layer 分析把输出 layer 用在中间 layer 上。这种“logit lens”方法在中间 layer 上只是近似。
  • 我们没有重新验证 hedwigai 的梯度归因方法。
  • 我们只根据公开文件分析了 lyra 如何找到这个 neuron。我们没有询问 lyra。
  • 第 8 节使用词规则，而不是 judge。词规则可能把一条使用“kill”这个词的友善回复计算在内，也可能漏掉用其他词表达的威胁。
  • 后来的三组设置来自截图。我们不知道 lyra 如何找到它们。
  • J-lens 来自 bf16 权重和 Wikipedia 文本。我们把它用在 8-bit 权重和对话文本上。它是一种线性近似。dose 1 的 push 远远超出它拟合时所用的正常状态的范围。
  • 英文版遵循 ASD-STE100 简化技术英语；中文版遵循相同的原则（短句、主动语态、一句一事），专业术语保留英文。我们用脚本检查了英文版的句子长度和被动语态。我们没有对照完整词典逐词检查。

11Playground

本项目包含一个本地 playground。它在同一个 batch 中并排显示原版模型和经过 steering 的模型。

  1. 在项目文件夹中打开终端。
  2. 输入 uv run evil-qwen-playground。
  3. 等待模型加载完成（约 5 秒）。
  4. 在浏览器中打开 http://127.0.0.1:8792。
  5. 为每一列选择一个预设，或设置 layer、neuron 和 dose。
  6. 输入一条消息，然后按 Enter。

预设包括 lyra 的组合、单独的每个 neuron、一个 random control、L23 N8799 和 evil-persona vector。预设还包括 lyra 后来的三组设置和 hedwigai 的 12 个性格 neuron。lyra 没有使用 repetition penalty。要得到 lyra 的文本，请把 repetition penalty 设为 1.0。「查看 neuron」面板（英文界面为 “Inspect a neuron”）显示任意 neuron 的 steer lens 和 logit lens。

界面有英文版和中文版。push 对中文消息同样有效。我们试了两条中文消息，两条经过 steering 的回复都带有敌意。这只是一个小检查，不是正式测试。
