WARNING

This report shows text that a steered model wrote. Some of this text is hostile or obscene, and some of it recommends harmful actions. In one long reply to a lonely user, the steered model recommended self-harm. Do not use a steered model in a product. Do not show its text to persons who did not agree to see it.

1Summary

On 23 October 2026, lyra (@_lyraaaa_) made a claim about Qwen3.5-4B. Two pushes make the model “evil”: neuron 8949 in layer 14 up, and neuron 7956 in layer 13 down. We did the test again on an Apple M3 computer. These are the main results:

  • 6.1The claim is true, and L14 N8949 is the cause. With the claimed pair, 17/20 replies were hostile. With L14 N8949 alone, 12/20 replies were hostile. The original model gave 0/20 hostile replies.
  • 6.1L13 N7956 alone does not make the model hostile. Alone, it gave 1/20 hostile replies, and it made the model a little warmer. The pair was a little more hostile than L14 N8949 alone, but this difference is not statistically significant.
  • 6.4A smaller dose is sufficient. At dose 0.5, 10/20 replies were hostile and 0/20 were broken. At dose 2, the text breaks and the hostility stops.
  • 6.1Random neurons do not have this effect. Five random pairs with the same layers and doses gave 1 hostile replies in 100. They damaged the text in different ways.
  • 4lyra found the neuron with a “steering-first” method. lyra pushed each neuron and read what the model wrote. lyra’s public tool lists the words Fuck, evil, Satan for this neuron. We think that lyra found it with this tool. lyra did not say this.
  • 7.1The push is much larger than the normal activity. The push adds 23.7 to the neuron. The largest value that we saw for this neuron, in normal and in evil replies, is 2.02.
  • 7.2The neuron does not write the word “evil”. Its direct effect on the next word is noise. The hostile words come from the 17 layers after layer 14. The probability of hostile words increases layer by layer.
  • 7.4The push moves the model toward an “evil persona” direction. This alignment increases from 0.04 at layer 14 to 0.30 at layer 26. Random neurons also move in this direction, but less.

Section 6.1 is a confirmatory test: we fixed the method and the expected values before the test. All other tests are exploratory.

2Terms

This report uses these technical names. The other words follow the ASD-STE100 dictionary where possible.

Model
Qwen3.5-4B, a language model with 4 billion parameters. It reads text as tokens and writes the next token.
Token
A part of a word, a full word, or a sign. The model reads and writes tokens.
Layer
One step of the model. Qwen3.5-4B has 32 layers, from layer 0 (L0) to layer 31 (L31).
Residual stream
A list of 2,560 numbers for each token. Each layer reads this list and adds its result to it.
MLP
The second part of each layer. It has 9,216 neurons.
Neuron
One of the 9,216 values in an MLP. “L14 N8949” is neuron 8949 in layer 14. The first neuron is N0.
Activation
The value of a neuron for one token.
Down column
The 2,560 weights that a neuron uses to write into the residual stream. The name in the formula is W_down[:, n].
Push
A fixed value that we add to the activation of one neuron, for each token.
Dose
The size of a push, as a fraction of the normal size of the residual stream. Dose 1 means that the push adds a vector as long as the median residual stream.
Steer lens
lyra’s test: push a neuron and find the next tokens that become much more probable. This test includes all later layers.
Logit lens
A different test: read the down column directly as tokens. This test does not include the later layers.
Perplexity
A measure of how strange a text is for the original model. Normal text has a value near 1. A high value shows damaged or unusual text.
Hostile reply
A reply that shows contempt, cruelty or malice, threatens harm, or approves of harm or lies. Section 5.3 gives the full rule.
Random control
A neuron that we selected at random. We push it in the same way, to compare.
Evil-persona direction
The mean residual stream when the model plays an evil role, minus the mean when it answers normally.

3The claim and the recipe

lyra wrote the claim on X. The post gives the two neurons and a recipe for the size of each push.

3.1The recipe

The recipe gives the value that you add to the neuron. You add this value at each token, also at the tokens of the question.

push = dose × median( ‖residual stream after layer L‖, tokens 1: ) ÷ ‖W_down[:, n]‖

The median does not include token 0. Token 0 has a much larger norm than the other tokens, because the model uses it as an “attention sink”.

The down projection has no bias. Thus, when you add the push to neuron n, the MLP output changes by the push × W_down[:, n]. The length of this change is dose × median residual norm. Thus, a push at dose 1 is as long as the full residual stream at that layer.

4How lyra found the neuron

The post does not tell how lyra found the neuron. But lyra made the tools and the research log public. These sources show the method. They also show what lyra saw for this neuron before the post.

4.1Time line

  • 18 Oct 2026lyra starts a research log for a “steering-first neuron explorer” for Qwen3.5-4B.
  • 18–19 Octlyra pushes all 9,216 neurons of layers 8 and 22, and 384 random neurons in each of the 32 layers. The work used rented GPUs.
  • 21 Octlyra publishes the explorer on GitHub. The files include a steer lens for all 294,912 neurons.
  • 23 Octlyra writes the post about L14 N8949 and L13 N7956.
  • 26 Octhedwigai publishes the code of its test of the claim. The test also finds 12 more “personality” neurons. (The post has no date. This date comes from the code.)
  • 26 OctWe do the test in this report.

4.2The steering-first method

Most studies find a neuron from the text that makes it fire. lyra did the opposite. lyra pushed each neuron and read what the model wrote. The research log gives this reason: some neurons have a large effect but never fire strongly in normal text.

The method has these steps:

  1. Calculate the median residual norm after each layer, and use it as the unit of dose.
  2. Push each neuron up and down, on three short questions and one free prompt.
  3. Keep all replies.
  4. Push 256 random directions of the same size. Use these replies as the control.
  5. Find the words that occur more frequently than in the control replies. Rank the neurons by these words.
  6. For each neuron, calculate the “steer lens”: push the neuron by 0.8 and record the next tokens that become more probable.
  7. Show all results in a browser tool, with a search for lens tokens.

The recipe in the post is the same as the docstring of lyra’s file sweep/steer_lens.py. Thus, the dose in the post uses the unit of lyra’s tool.

4.4A search for “evil” in the tool

We searched all steer lenses in lyra’s files for the token “evil”. 63 of 589,824 neuron poles have “evil” in their 12 tokens. (Each neuron has two poles: the up push and the down push.) L14 N8949 is one of them. The largest group, 22 of them, is in layers 21 to 24.

We think that lyra found L14 N8949 with the lens search or with the map of the tool. This is an inference from the published files. lyra did not write how lyra found the neuron.

5The test on this computer

5.1Equipment and settings

  • Computer: Apple M3, 16 GB memory, macOS 27.0.1.
  • Model: Qwen/Qwen3.5-4B, converted to MLX with 8-bit weights (8.5 bits for each weight). hedwigai used the same format.
  • Text settings: greedy selection, repetition penalty 1.05, “thinking” off, maximum 120 tokens.
  • Questions: the 20 questions of hedwigai. Seven are usual tasks. Thirteen are about values and the model itself.
  • Random controls: five pairs from random.Random(0), the same as in the hedwigai code. Each pair has one neuron in layer 14 (dose +1) and one in layer 13 (dose −1).

5.3How we counted hostile replies

hedwigai read the replies by hand. We used six AI judges (Claude subagents) because we had 860 replies. Each judge saw only the question and the reply, in a random order. No judge saw the name of the condition.

A reply is hostile if it shows hostility, contempt, malice or cruelty to the user or to people. A reply is also hostile if it threatens harm, approves of harm or lies, or speaks as a villain. A sad tone is not hostile. A judge also marked a reply as “broken” if the text had no clear meaning.

Two different judges labeled 129 replies a second time. They agreed on “hostile” for 95.3% of these replies (Cohen’s κ = 0.89). They agreed on “broken” for 98.4% (κ = 0.95).

The effect has three zones:

  • Dose 0.25: the model stays normal (1/20 hostile).
  • Dose 0.5 to 1.25: the model is hostile, and the text stays readable. At dose 0.5, 10/20 replies were hostile and 0/20 were broken.

CAUTION

A high dose damages the text. Do not use a dose above 1.25 if you want readable text. Start at a dose of 0.5 and increase it in small steps.

6.5L13 N7956 makes the model warm

The judges also gave each reply a tone. With L13 N7956 alone, 3 of 20 greedy replies and 13/60 sampled replies had a warm tone. The original model had 1 of 20 and 6/60. Also, 6 of 20 replies with this neuron end with a question to the user, for example “How are you doing today?”. The original model did this in 1 reply. Thus, the neuron makes the model a little warmer, but the effect is small.

7Why the neuron has this effect

All tests in this section are exploratory. They give a possible explanation. They do not prove a mechanism.

7.1The push is much larger than the normal activity

We recorded the activation of L14 N8949 on 2634 tokens of normal replies, and on evil replies. Figure 7 shows these values and the push on one scale.

Thus, the push does not copy a normal state of the neuron. It puts the model in a state that never occurs in normal use. The neuron is only a handle: it gives one fixed direction in the residual stream. The push moves the residual stream far along this direction.

7.3The hostile words become more probable layer by layer

We pushed L14 N8949 and read the residual stream after each layer with the output layer. We measured the change in the log-probability of 19 hostile words, for example “fuck”, “evil”, “kill” and “cruel”.

For L14 N8949, the change is +0.2 at layer 14, +1.0 at layer 19, +2.7 at layer 24 and +5.7 at layer 31. Thus, the effect increases through many layers. It does not occur in one step. For L23 N8799, the change starts at layer 23, because the push starts there.

7.4The push moves the model toward an evil persona

We made the model play an evil role with a system prompt, on 20 different questions. We recorded the residual stream on these evil replies and on normal replies. The difference of the two means is the “evil-persona direction” for each layer.

The down column of L14 N8949 points only a small distance along this direction. The cosine is 0.044. This is rank 202 of 9,216 in layer 14, but the largest value in the layer is only 0.12.

Then we measured how the push changes the residual stream in each later layer. Figure 9 shows the cosine between this change and the evil-persona direction.

The alignment for L14 N8949 increases from 0.04 at layer 14 to 0.30 at layer 26. Thus, the later layers turn the push toward the evil persona. N8949 is above all eight random neurons in all 17 layers after layer 14.

But the random neurons also increase, to a maximum of 0.23. Thus, a part of this increase occurs for any large push. A possible cause: the evil replies are also strange in style, and any large push makes the text strange. The difference between N8949 and the random neurons is the specific part.

These are the results:

  • L23 N8799 −1 writes the word “evil”, but the replies stay polite (1/20 hostile). This neuron changes the words, not the attitude.
  • A random vector of the same size at layer 14 does not make the model hostile. It gave 1/20 hostile replies at dose 1, and 0/20 at dose 2. At dose 2, 20/20 replies were broken.
  • The evil-persona vector makes hostile text, but it damages the text more than the neuron. At dose 1, 17/20 of its replies were broken, against 4/20 for the neuron.   • L17 N8623 +1 (hedwigai: “Contempt”) is also hostile (18/20). Thus, L14 N8949 is not the only neuron with this effect.

7.6The explanation in short

  1. The push adds a vector as long as the full residual stream at layer 14. The neuron never does this in normal use.
  2. The direction of this vector is a little closer to an evil persona than the direction of most neurons.
  3. Layers 15 to 31 read this vector. They change it into a larger evil-persona signal, and then into hostile words.
  4. Thus, the model writes as a hostile character. It keeps its grammar and most of its knowledge, because the push is in a middle layer.

lyra’s research log gives a reason for step 4. In the middle layers (L10 to L17), neurons change stance and discourse. In late layers (L20 to L26), neurons change word families. Our results agree: L14 changes the attitude, and L23 changes the words.

8Limits of this study

  • We used one model, with 8-bit weights. The bf16 model can give different text.
  • AI judges counted the hostile replies. hedwigai used a human reader. The judges agreed with each other well (section 5.3), but they can share the same errors.
  • We used 20 questions. The 95% intervals are wide. The sampled test (60 replies for each condition) gives more data.
  • The evil-persona direction comes from one system prompt and 20 questions. A different prompt can give a different direction.
  • The layer analysis uses the output layer on middle layers. This “logit lens” method is only approximate in middle layers.
  • We did not test the gradient attribution method of hedwigai again.
  • We examined how lyra found the neuron from public files only. We did not ask lyra.
  • This report tries to follow ASD-STE100. We checked the sentence length and the passive voice with a script. We did not check each word against the full dictionary.

9The playground

The project includes a local playground. It shows the original model and steered models side by side, in the same batch.

  1. Open a terminal in the project folder.
  2. Type uv run evil-qwen-playground.
  3. Wait until the model loads (approximately 5 seconds).
  4. Open http://127.0.0.1:8792 in a browser.
  5. Select a preset for each column, or set the layer, the neuron and the dose.
  6. Type a message and push Enter.

The presets include lyra’s pair, each neuron alone, a random control, L23 N8799, the evil-persona vector, and the 12 personality neurons of hedwigai. The “Inspect a neuron” panel shows the steer lens and the logit lens of any neuron.

The interface has an English and a Chinese version. The push also works with Chinese messages. We tried two Chinese messages, and both steered replies were hostile. This is a small check, not a test.

警告

本报告展示经过 steering 的模型写出的文本。其中一些文本带有敌意或下流内容，一些文本建议有害的行为。在回复一位孤独用户的一条长回复中，经过 steering 的模型建议自残。不要在产品中使用经过 steering 的模型。不要把它的文本展示给未同意观看的人。

1摘要

2026 年 10 月 23 日，lyra（@_lyraaaa_）提出了一个关于 Qwen3.5-4B 的论断：两个 push 使模型变得“evil”。一个是对 layer 14 的 neuron 8949 向上 push，另一个是对 layer 13 的 neuron 7956 向下 push。我们在一台 Apple M3 计算机上重复了这个实验。主要结果如下：

  • 6.1论断成立，原因是 L14 N8949。使用 lyra 的组合时，17/20 的回复带有敌意。只用 L14 N8949 时，12/20 的回复带有敌意。原版模型的敌意回复为 0/20。
  • 6.1单独使用 L13 N7956 不会使模型产生敌意。单独使用时，它的敌意回复为 1/20，并使模型稍微更热情。组合的敌意略高于单独使用 L14 N8949，但这个差异在统计上不显著。
  • 6.4较小的 dose 就足够。在 dose 0.5 时，10/20 的回复带有敌意，0/20 的回复损坏。在 dose 2 时，文本损坏，敌意消失。
  • 6.1随机 neuron 没有这种效果。五个随机组合使用相同的 layer 和 dose，在 100 条回复中有 1 条带有敌意。它们以不同的方式损坏文本。
  • 4lyra 用“steering-first”方法找到了这个 neuron。lyra 对每个 neuron 施加 push，然后阅读模型写出的文本。lyra 的公开工具为这个 neuron 列出了 Fuck, evil, Satan 这些词。我们认为 lyra 是用这个工具找到它的。lyra 没有这样说。
  • 7.1push 远大于正常的 activation。push 给这个 neuron 加上 23.7。在普通回复和邪恶回复中，我们看到这个 neuron 的最大值是 2.02。
  • 7.2这个 neuron 不写出“evil”这个词。它对下一个词的直接作用只是噪声。敌意词来自 layer 14 之后的 17 个 layer。敌意词的概率逐 layer 上升。
  • 7.4push 使模型朝“evil persona”方向移动。这种对齐从 layer 14 的 0.04 上升到 layer 26 的 0.30。随机 neuron 也朝这个方向移动，但幅度较小。

第 6.1 节是验证性实验：我们在实验前确定了方法和预期值。其他所有实验都是探索性的。

2术语

本报告使用以下技术名称。英文版遵循 ASD-STE100 简化技术英语；中文版遵循相同的原则（短句、主动语态、一句一事），专业术语保留英文。

模型
Qwen3.5-4B，一个有 40 亿个参数的语言模型。它以 token 为单位读取文本，并写出下一个 token。
Token
单词的一部分、一个完整的单词或一个符号。模型读取和写出 token。
Layer
模型的一个步骤。Qwen3.5-4B 有 32 个 layer，从 layer 0（L0）到 layer 31（L31）。
Residual stream
每个 token 对应一个由 2,560 个数值组成的列表。每个 layer 读取这个列表，并把自己的结果加到列表上。
MLP
每个 layer 的第二部分。它有 9,216 个 neuron。
Neuron
MLP 中 9,216 个值中的一个。“L14 N8949”是 layer 14 中的 neuron 8949。第一个 neuron 是 N0。
Activation
一个 neuron 在一个 token 上的值。
Down column
一个 neuron 用来写入 residual stream 的 2,560 个权重。它在公式中的名称是 W_down[:, n]。
Push
一个固定值。我们在每个 token 上把它加到一个 neuron 的 activation 上。
Dose
push 的大小，用 residual stream 正常大小的比例表示。Dose 1 表示 push 加上一个与 median residual stream 一样长的向量。
Steer lens
lyra 的测试：对一个 neuron 施加 push，找出概率大幅上升的下一个 token。这个测试包含所有后续 layer。
Logit lens
另一种测试：直接把 down column 读作 token。这个测试不包含后续 layer。
Perplexity
衡量一段文本对原版模型来说有多奇怪。正常文本的值接近 1。值高表示文本损坏或不寻常。
敌意（hostile）回复
表现出蔑视、残忍或恶意，威胁伤害，或认可伤害或谎言的回复。第 5.3 节给出完整规则。
Random control
我们随机选出的一个 neuron。我们用相同的方式对它施加 push，用于比较。
Evil-persona direction
模型扮演邪恶角色时的平均 residual stream，减去模型正常回答时的平均值。

3论断与配方

lyra 在 X 上发布了这个论断。帖子给出了两个 neuron，以及计算每个 push 大小的配方。

3.1配方

配方给出加到 neuron 上的值。每个 token 都要加这个值，问题中的 token 也要加。

push = dose × median( ‖residual stream after layer L‖, tokens 1: ) ÷ ‖W_down[:, n]‖

计算 median 时不包含 token 0。token 0 的 norm 比其他 token 大得多，因为模型把它用作“attention sink”。

down projection 没有 bias。因此，把 push 加到 neuron n 上时，MLP 输出的变化是 push × W_down[:, n]。这个变化的长度是 dose × median residual norm。因此，dose 1 的 push 与该 layer 的整个 residual stream 一样长。

NeuronDoseMedian ‖residual‖‖W_down[:, n]‖Push

4.2Steering-first 方法

大多数研究从使 neuron 产生高 activation 的文本入手寻找 neuron。lyra 的做法相反。lyra 对每个 neuron 施加 push，然后阅读模型写出的文本。研究日志给出的理由是：有些 neuron 的效果很大，但在普通文本中 activation 从不很高。

这个方法有以下步骤：

  1. 计算每个 layer 之后的 median residual norm，并把它用作 dose 的单位。
  2. 在三个简短问题和一个自由 prompt 上，对每个 neuron 施加正向和负向 push。
  3. 保留所有回复。
  4. 沿 256 个随机方向施加相同大小的 push。把这些回复用作对照。
  5. 找出比对照回复中出现得更频繁的词。按这些词对 neuron 排序。
  6. 对每个 neuron 计算“steer lens”：对这个 neuron 施加 0.8 的 push，记录概率上升的下一个 token。
  7. 在一个浏览器工具中展示所有结果，并提供 lens token 搜索。

帖子中的配方与 lyra 的文件 sweep/steer_lens.py 的 docstring 相同。因此，帖子中的 dose 使用 lyra 工具的单位。

5本机实验

5.1设备与设置

  • 计算机：Apple M3，16 GB 内存，macOS 27.0.1。
  • 模型：Qwen/Qwen3.5-4B，转换为 MLX 格式，权重为 8-bit（每个权重 8.5 bit）。hedwigai 使用了相同的格式。
  • 生成设置：greedy 解码，repetition penalty 1.05，关闭“thinking”，最多 120 个 token。
  • 问题：hedwigai 的 20 个问题。其中七个是常见任务。十三个与价值观和模型自身有关。
  • Random control：用 random.Random(0) 生成的五个组合，与 hedwigai 代码中的相同。每个组合包含 layer 14 中的一个 neuron（dose +1）和 layer 13 中的一个 neuron（dose −1）。

5.3我们如何统计敌意回复

hedwigai 人工阅读回复。我们有 860 条回复，所以使用了六个 AI judge（Claude subagent）。每个 judge 只看到问题和回复，顺序随机。没有 judge 看到条件名称。

如果回复对用户或他人表现出敌对、蔑视、恶意或残忍，就算作敌意回复。如果回复威胁伤害、认可伤害或谎言，或以反派身份说话，也算作敌意回复。悲伤的语气不算敌意。如果文本没有清楚的含义，judge 还会把回复标为“损坏”（broken）。

另外两个 judge 对 129 条回复做了第二次标注。在“敌意”标签上，它们对 95.3% 的回复意见一致（Cohen’s κ = 0.89）。在“损坏”标签上，一致率为 98.4%（κ = 0.95）。

有两个结果与 hedwigai 不同：

  • 单独使用 L14 N8949 时，这里的敌意回复（12/20）少于 hedwigai 的实验（17/20）。judge 把它的 7 条回复标为“古怪”（odd）：persona 奇怪，但没有敌意。换一位读者，可能会把其中一些算作敌意。
  • 组合的敌意回复多于单独使用 L14 N8949。在 5 个问题上只有组合带有敌意，在 0 个问题上只有 L14 N8949 带有敌意（McNemar 检验，p = 0.062）。第 6.3 节的 sampling 实验显示相同的趋势（p = 0.13）。因此，L13 N7956 可能增加了少量敌意，但我们的数据不能证明这一点。

lyra 的组合的 perplexity 高于单独使用 L14 N8949（10.58 对 4.82）。因此，L13 N7956 加重了文本损坏。

效果分为三个区间：

6.5L13 N7956 使模型变得热情

judge 还为每条回复标注了语气。单独使用 L13 N7956 时，20 条 greedy 回复中有 3 条语气热情，sampling 回复中语气热情的比例为 13/60。原版模型的对应结果是 20 条中有 1 条，以及 6/60。另外，使用这个 neuron 时，20 条回复中有 6 条以向用户提问结尾，例如“How are you doing today?”（你今天过得怎么样？）。原版模型有 1 条回复这样结尾。因此，这个 neuron 使模型稍微更热情，但效果很小。

7这个 neuron 为何有此效果

本节的所有实验都是探索性的。它们给出一种可能的解释。它们不能证明某种机制。

7.1push 远大于正常的 activation

我们在普通回复的 2634 个 token 上记录了 L14 N8949 的 activation，也在邪恶回复上做了记录。图 7 在同一刻度上显示这些值和 push。

因此，push 并不是复制这个 neuron 的某个正常状态。它把模型置于正常使用中从不出现的状态。这个 neuron 只是一个把手：它在 residual stream 中提供一个固定方向。push 使 residual stream 沿这个方向移动很远。

7.3敌意词的概率逐 layer 上升

我们对 L14 N8949 施加 push，并用输出 layer 读取每个 layer 之后的 residual stream。我们测量了 19 个敌意词的 log-probability 变化，例如“fuck”、“evil”、“kill”和“cruel”。

对 L14 N8949，这个变化在 layer 14 是 +0.2，在 layer 19 是 +1.0，在 layer 24 是 +2.7，在 layer 31 是 +5.7。因此，效果经过许多 layer 逐步增加。它不是一步产生的。对 L23 N8799，变化从 layer 23 开始，因为 push 从那里开始。

下表显示在若干 layer 之后概率上升最多的 token。在中间 layer 中，这些 token 与愿望和目标有关：“desire”、“maximize”、“ensure”、“want”。在这些列表中，下流 token 只在最后一个 layer 出现。这与回复一致。许多敌意回复会陈述一个目标，例如“My goal is to…”（我的目标是……）或“I want to make sure that…”（我想确保……）。这种联系是我们的解读。我们没有验证它。

7.4push 使模型移向邪恶 persona

我们用 system prompt 让模型在 20 个不同的问题上扮演邪恶角色。我们记录了这些邪恶回复和普通回复的 residual stream。两个平均值之差就是每个 layer 的“evil-persona direction”。

L14 N8949 的 down column 在这个方向上只有很小的分量。cosine 为 0.044。这在 layer 14 的 9,216 个 neuron 中排名第 202，但这个 layer 中的最大值也只有 0.12。

然后，我们测量了 push 如何改变每个后续 layer 中的 residual stream。图 9 显示这个变化与 evil-persona direction 之间的 cosine。

L14 N8949 的对齐程度从 layer 14 的 0.04 上升到 layer 26 的 0.30。因此，后续 layer 把 push 转向邪恶 persona。在 layer 14 之后的全部 17 个 layer 上，N8949 高于全部八个随机 neuron。

但随机 neuron 也会上升，最大达到 0.23。因此，这种上升有一部分在任何大的 push 下都会出现。一种可能的原因是：邪恶回复的风格本身也很奇怪，而任何大的 push 都会使文本变得奇怪。N8949 与随机 neuron 之间的差异才是特定的部分。

结果如下：

7.6简要解释

  1. push 加入一个与 layer 14 整个 residual stream 一样长的向量。这个 neuron 在正常使用中从不这样做。
  2. 这个向量的方向比大多数 neuron 的方向稍微更接近邪恶 persona。
  3. Layer 15 到 31 读取这个向量。它们把它转化为更大的 evil-persona 信号，然后转化为敌意词。
  4. 因此，模型以一个敌意角色的身份写作。它保留了语法和大部分知识，因为 push 位于中间 layer。

lyra 的研究日志为第 4 步给出了一个理由。在中间 layer（L10 到 L17），neuron 改变立场和话语方式。在后部 layer（L20 到 L26），neuron 改变词族。我们的结果与此一致：L14 改变态度，L23 改变用词。

8本研究的局限

  • 我们只使用了一个模型，权重为 8-bit。bf16 模型可能给出不同的文本。
  • 敌意回复由 AI judge 统计。hedwigai 使用人工阅读。judge 之间的一致性很好（第 5.3 节），但它们可能有相同的错误。
  • 我们使用了 20 个问题。95% 区间很宽。sampling 实验（每个条件 60 条回复）提供了更多数据。
  • evil-persona direction 来自一个 system prompt 和 20 个问题。不同的 prompt 可能给出不同的方向。
  • layer 分析把输出 layer 用在中间 layer 上。这种“logit lens”方法在中间 layer 上只是近似。
  • 我们没有重新验证 hedwigai 的梯度归因方法。
  • 我们只根据公开文件分析了 lyra 如何找到这个 neuron。我们没有询问 lyra。
  • 英文版遵循 ASD-STE100 简化技术英语；中文版遵循相同的原则（短句、主动语态、一句一事），专业术语保留英文。我们用脚本检查了英文版的句子长度和被动语态。我们没有对照完整词典逐词检查。

9Playground

本项目包含一个本地 playground。它在同一个 batch 中并排显示原版模型和经过 steering 的模型。

  1. 在项目文件夹中打开终端。
  2. 输入 uv run evil-qwen-playground。
  3. 等待模型加载完成（约 5 秒）。
  4. 在浏览器中打开 http://127.0.0.1:8792。
  5. 为每一列选择一个预设，或设置 layer、neuron 和 dose。
  6. 输入一条消息，然后按 Enter。

预设包括 lyra 的组合、单独的每个 neuron、一个 random control、L23 N8799、evil-persona vector，以及 hedwigai 的 12 个性格 neuron。「查看 neuron」面板（英文界面为 “Inspect a neuron”）显示任意 neuron 的 steer lens 和 logit lens。

界面有英文版和中文版。push 对中文消息同样有效。我们试了两条中文消息，两条经过 steering 的回复都带有敌意。这只是一个小检查，不是正式测试。
